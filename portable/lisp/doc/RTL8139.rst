Драйвер сетевой карты RTL8139
=============================

Драйвер обеспечивает передачу и приём кадров Ethernet через сетевую карту
Realtek RTL8139.

Драйвер работает опросом регистров, прерывания не используются.

Кадр представляется массивом байт:
::

   [Получатель 6][Отправитель 6][Тип 2][Данные 46..1500]

Преамбулу, признак начала кадра (SFD) и контрольную сумму (FCS) добавляет при
передаче и проверяет при приёме сама карта, в массиве их нет.

MAC-адрес представляется массивом из 6 байт.

Интерфейсы
----------

:rtl-list: Поиск карт RTL8139 на шине PCI. Параметров нет.
           Возвращает список MAC-адресов найденных карт,
           пустой список, если карт нет.
:rtl-init mac: Инициализация карты с MAC-адресом mac: сброс, выделение
               буферов, включение приёма и передачи.
               Возвращает t.
               Ошибка, если карта с таким адресом не найдена.
:rtl-send src dst data: Передача данных data с карты с MAC-адресом src
                        на MAC-адрес dst.
                        Параметр data - массив байт длиной до 1500.
                        Кадр формируется внутри функции.
                        Возвращает t, когда карта отправила кадр.
                        Ошибка, если карта не инициализирована, данные
                        слишком длинные или передача прервана.
:rtl-recv mac: Приём одного кадра картой с MAC-адресом mac.
               Возвращает список (src data), где src - MAC-адрес
               отправителя, data - массив байт с данными,
               или nil, если кадров нет.
               Ошибка, если карта не инициализирована.

Если данных меньше 46 байт, кадр дополняется нулями, и при приёме
эти нули возвращаются вместе с данными.

MAC-адрес карты для функций rtl-init, rtl-send и rtl-recv берётся
из результата rtl-list.

Функции rtl-send и rtl-recv можно вызывать только для карты,
для которой выполнена rtl-init.

Успешная передача означает только то, что кадр отправлен в кабель,
доставка получателю не гарантируется.
